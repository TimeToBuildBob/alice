### 3. Enhanced uvx Detection
**Issue**: `"uv" in sys.prefix` too broad → false positives like `/home/uvalde/`

**Fix**: Comprehensive cross-platform patterns
```python
if (
    "/.uv/" in sys.prefix          # Unix hidden
    or "\\.uv\\" in sys.prefix     # Windows hidden
    or "/uv/" in sys.prefix        # Unix regular
    or "\\uv\\" in sys.prefix      # Windows regular
    or sys.prefix.endswith("/.uv") # Unix suffix
    or sys.prefix.endswith("\\.uv")# Windows suffix
    or sys.prefix.endswith("/uv")  # Unix suffix
    or sys.prefix.endswith("\\uv") # Windows suffix
    or os.environ.get("UV_HOME")
):
    return "uvx"
```

**Testing**: Verified against false positives and true positives
